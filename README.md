## Τι είναι αυτό;

Μια επιλεγμένη λίστα, που ενημερώνεται κάθε εβδομάδα, με τους 1.059 actors για e-commerce που χρησιμοποιούνται πραγματικά, από τους 13.333 actors της κατηγορίας E-commerce του Apify Store, μαζί με τα εργαλεία για Skroutz και ελληνικά e-shops. Οι actors που δεν έτρεξε κανείς τις τελευταίες 30 ημέρες αφαιρούνται, και κάθε actor είναι ταξινομημένος ανά κατάστημα ή εργασία, ώστε να βρείτε σε δευτερόλεπτα ένα εργαλείο για έρευνα προϊόντων, παρακολούθηση τιμών, ανάλυση κριτικών ή dropshipping.

Κάθε εγγραφή είναι ένα εργαλείο στο cloud (ένας «Actor») της πλατφόρμας Apify: το ανοίγετε, συμπληρώνετε τα στοιχεία εισόδου, πατάτε Start και κατεβάζετε τα αποτελέσματα σε JSON, CSV ή Excel, ή το καλείτε από τον κώδικά σας μέσω του Apify API. Κάθε νέος λογαριασμός παίρνει δωρεάν μηνιαία πίστωση, αρκετή για να δοκιμάσετε τους περισσότερους actors χωρίς χρέωση.

> Οι τίτλοι και οι περιγραφές των actors προέρχονται αυτούσιοι από το Apify Store, συνήθως στα αγγλικά. Οι φόρμες εισόδου δέχονται αναζητήσεις στα ελληνικά.

Δείτε την ενότητα Skroutz και ελληνικά e-shops. Ο Skroutz Scraper της ομάδας μας καλύπτει Ελλάδα, Κύπρο, Βουλγαρία, Ρουμανία και Γερμανία, με προσφορές καταστημάτων και ιστορικό τιμών.

### Μπορώ να παρακολουθώ αυτόματα τις τιμές των ανταγωνιστών;

Ναι. Προγραμματίστε οποιονδήποτε actor προϊόντων ή τιμών να τρέχει καθημερινά και χρησιμοποιήστε την ενότητα σύγκρισης τιμών για εργαλεία που καταγράφουν αλλαγές στον χρόνο.

### Είναι νόμιμη η συλλογή δεδομένων προϊόντων;

Η συλλογή δημόσιων πληροφοριών για προϊόντα και τιμές είναι συνηθισμένη πρακτική, αλλά ελέγξτε τους όρους του site και τη νομοθεσία, και μη συλλέγετε προσωπικά δεδομένα που δεν χρειάζεστε (GDPR).

### Χρειάζομαι proxies ή δικούς μου servers;

Όχι. Οι actors τρέχουν στο cloud του Apify και διαχειρίζονται proxies, browsers και προστασίες anti-bot για εσάς.

### Πόσο συχνά ενημερώνεται η λίστα;

Ένα GitHub Action την ξαναφτιάχνει κάθε εβδομάδα από το δημόσιο API του Apify Store, έτσι οι νέοι actors εμφανίζονται και οι εγκαταλελειμμένοι αφαιρούνται αυτόματα.

### Μπορώ να προσθέσω τον δικό μου actor;

Δημοσιεύστε τον στο Apify Store στην κατηγορία E-commerce. Μόλις αρχίσει να χρησιμοποιείται, μπαίνει στη λίστα με την επόμενη εβδομαδιαία ενημέρωση. Δεν χρειάζεται pull request.
