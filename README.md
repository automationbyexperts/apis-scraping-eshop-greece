Μια επιλεγμένη λίστα, που ενημερώνεται κάθε εβδομάδα, με τους 1.053 actors για e-commerce που χρησιμοποιούνται πραγματικά, από τους 16.050 actors της κατηγορίας E-commerce του Apify Store, μαζί με τα εργαλεία για Skroutz και ελληνικά e-shops.
